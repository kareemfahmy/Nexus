# Nexus Design System: Master File

> **Logic:** when building a page, first check `design-system/nexus/pages/[page-name].md`.
> If that file exists, its rules override this Master. Otherwise, follow this file.
>
> **Origin:** generated by the ui-ux-pro-max skill (`--design-system --density 8 --variance 3 --motion 2`),
> then adjusted to the decisions approved in `docs/architecture-plan.md`:
> - **light theme only** (the tool suggested dark)
> - **IBM Plex Sans + Plex Mono** (the tool suggested Fira Code headings)
> - **indigo accent** (the tool suggested green CTA, which clashes with the "online" status colour)
>
> **Implementation:** `src/styles/_primitives.scss` → `_semantic.scss` → `_components.scss`.
> Components must use **semantic or component tokens only**, never raw hex.

**Category:** Enterprise operations / IoT management SaaS
**Style:** Minimalism & Swiss Style: grid-based, high contrast, functional, essential
**Dials:** Variance 3 (minimal) · Motion 2 (subtle) · Density 8 (dense dashboard)

## 2. Typography
- **UI:** IBM Plex Sans 400 / 500 / 600. **Data and IDs:** IBM Plex Mono 400 / 500 (WO-100245, serials, MACs).
- Loaded from Google Fonts with `display=swap` and preconnect.
- Base size is **14px**. This is a deliberate dense-desktop deviation from the skill's 16px mobile rule. Inputs are 14px on desktop and 16px under 768px to avoid iOS zoom.
- Scale: `12 / 13 / 14 / 16 / 20 / 24`. Line height 1.5 for body, 1.25 for headings. Nothing smaller than 12px.
- Weights: headings 600, labels 500, body 400.
- `font-variant-numeric: tabular-nums` in tables, KPIs and timestamps.

## 3. Spacing, radius, elevation, z-index
- 4px scale: `--space-1 … --space-10` = 4, 8, 12, 16, 20, 24, 32, 40, 48, 64.
- Radius: `--radius-sm 4px` (badges, inputs), `--radius-md 6px` (cards, buttons), `--radius-lg 8px` (dialogs). No pill cards.
- Elevation is mostly borders: `--shadow-sm` for dropdowns, `--shadow-md` for drawers, `--shadow-lg` for dialogs. Cards don't get shadows.
- Z-index: base 0, sticky 10, sidebar 20, overlay 40, drawer 50, dialog 60, toast 100.

## 4. Components (density)
| Component | Spec |
|---|---|
| Button | Heights 32 (default), 28 (sm), 40 (lg). Primary is accent; secondary is surface + border; ghost; danger. One primary per view. Shows a spinner and is disabled while busy. |
| Input / select | 32px high (40px under 768px), 1px control border, visible label, error text below linked with `aria-describedby`. Validate on blur. |
| Table | 36px rows (32 compact), sticky header on subtle surface, row hover, `aria-sort` on sortable headers, tabular numbers, row click opens the detail page. |
| Badge / StatusBadge | 20px high, radius-sm, dot + text. Icon optional. |
| Card / panel | Surface, 1px border, radius-md, 16px padding. |
| Dialog | Max 480px, radius-lg, focus trap, Esc closes, confirm required for destructive actions. |
| Drawer | 480px right side, used for quick preview of WOs and incidents. |
| Toast | Bottom-right, `aria-live=polite`, 4s auto-dismiss, never steals focus. |
| Sidebar | 232px (64px rail when collapsed). Grouped sections. Active item uses accent-subtle bg + accent text + 2px indicator. |

## 5. Motion
- Durations: `--duration-fast 120ms` (hover, press), `--duration-base 180ms` (expand, fade), `--duration-slow 240ms` (drawer, dialog enter). Exit is about 70% of enter.
- Easing: `--ease-out cubic-bezier(0.2, 0, 0, 1)` for enter, `--ease-in cubic-bezier(0.4, 0, 1, 1)` for exit.
- Only transform and opacity are animated. `prefers-reduced-motion: reduce` disables non-essential motion.
- No GSAP. The skill's GSAP snippet targets marketing pages and isn't used in Nexus.

## 6. Layout
- Breakpoints: 375 / 768 / 1024 / 1440. The sidebar becomes a drawer under 1024.
- Content max width is unbounded for tables. Forms and readable text cap at 720px.
- Never allow horizontal page scroll. Wide tables scroll inside their own container.

## Anti-patterns (do not use)
- Emoji icons. Use Lucide via `@lucide/angular` only.
- Colour-only status
- Raw hex in components
- Oversized KPI numbers that waste space
- Gradient-heavy or decorative cards
- A View/Edit/Delete button triplet on every row
- Placeholder-only labels
- Removing focus rings
- Instant (0ms) state changes or layout-shifting hovers

## Pre-delivery checklist
- [ ] Text contrast ≥ 4.5:1, control and icon contrast ≥ 3:1
- [ ] Visible focus on every interactive element. Tab order matches visual order.
- [ ] Icon-only buttons have `aria-label`. Decorative icons are `aria-hidden`.
- [ ] Loading (skeleton), empty (message + action) and error (message + retry) states exist
- [ ] `prefers-reduced-motion` respected
- [ ] Checked at 375, 768, 1024 and 1440 with no horizontal page scroll
- [ ] `validate-tokens.cjs` reports no hardcoded colours in `src/app`
